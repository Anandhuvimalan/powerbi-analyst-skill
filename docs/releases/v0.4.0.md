# v0.4.0: Project-derived visual design, rendered background panels, designed filters

Screenshots from Power BI Desktop showed that reports built with v0.3.0 lost their
design in three ways. This release fixes each one in the executor and adds
validation so it cannot come back.

## Fixed
- **Background shapes never rendered.** Background-layer elements were written at
  `z = -1000`, and Desktop does not draw visuals with a negative z. They now stack
  from z 0, below all content. Negative z and backgrounds above content are
  rejected.
- **Visual titles were dropped.** The plan's `title` was never written, so Power BI
  showed auto-titles. It is now rendered as the container title (`show_title`,
  `subtitle` supported). Slicers use it as their own header, so it is not printed
  twice.
- **Integer shape properties** were encoded as doubles (`12D`). Corners now compile
  to `12L`, and double-encoded integers are rejected.

## Added
- `style` / `style_defaults`: typed tokens that compile to native PBIR. Covers
  container background, border, radius, shadow, padding, header icons and title;
  shape fill, outline and corner; and `card_outline`.
- `slicer` settings: mode, single-select, select-all, header, item styling, and
  a native `syncGroup`.
- `label` on field bindings, written as the projection `displayName`.
- `design_system` in the report plan: concept, `derived_from` project facts,
  tokens, typography, grid and filter strategy.
- New skill reference `visual-design-system.md`.

## New validation
- **Agent mode requires:** a design system; a palette that is not the preset demo
  palette; panels or a card treatment on multi-visual pages.
- **Report validation rejects:**
  - unfilled shapes;
  - cards that never decide their inner outline;
  - slicers with no field or no chosen mode;
  - dropdown slicers under 76 px, and textboxes too short for their font (both
    mirror Microsoft's floors).
- **Report validation warns about:**
  - multi-page reports without navigation;
  - the same slicer on several pages without a sync group.

## Verification
The Microsoft report CLI validates a styled two-page build with 0 errors and
0 warnings, including remote schema validation. The build was opened, reloaded
and screenshotted in Power BI Desktop 2.157.
